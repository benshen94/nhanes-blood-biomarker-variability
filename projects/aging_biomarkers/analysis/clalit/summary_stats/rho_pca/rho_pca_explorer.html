Clalit Summary-Stat Spearman-Rho PCA

PCA on complete-case Clalit biomarker Spearman rhos across quartile-derived median, IQR-over-median CV, and quantile-skewness summaries. The normalization selector applies to the smoothed trajectories before rho is computed; the PCA method selector changes which rho features enter the PCA.

2D uses non-overlap placement. 3D falls back to direct labels.
11 px

What the normalization choices mean

These options normalize each smoothed age trajectory before Spearman rho is computed against age. The rho values are not normalized afterward.

rawUses the smoothed metric as-is across age. Keeps absolute direction and scale.
young_ratioDivides the trajectory by its young-reference value, so age 20-24 acts as baseline.
young_log_foldTakes log of the young-reference ratio. Only valid when the full smoothed trajectory stays positive.
shape_zZ-scores the trajectory across age points. This removes level and keeps only trajectory shape.

What the PCA methods change

Each method changes the feature matrix that enters PCA. `abs(...)` means the rho feature is transformed before PCA, not that a separate absolute trajectory was smoothed.

Signed all 3Signed rho_median, rho_cv, and rho_quantile_skewness.
Abs median, all 3abs(rho_median) with rho_cv and rho_quantile_skewness left signed.
Abs all 3abs(rho_median), abs(rho_cv), and abs(rho_quantile_skewness).
